# Changelog

## 0.1.0

- Native desktop launcher with a bundled .NET runtime.
- Simple account list with Add, Open, Rename, Delete, and tray menu.
- Temporary browser sign-in routing with crash recovery and a manual Google callback fallback.
- Store/standalone Claude discovery and executable override.
- Atomic configuration saves, backup recovery, and legacy prototype data support.
- Per-user installer/uninstaller preserving account profiles.
- MIT-licensed source, regression runner, and GitHub build workflows.

Preview compatibility: isolated process startup observed on Windows ARM64 with Claude Desktop Store 4.23118.0. Full authenticated multi-account behavior has not been certified.

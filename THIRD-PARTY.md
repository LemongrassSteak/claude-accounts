# Third-party components

The launcher source and original geometric icon are MIT-licensed under LICENSE.

Self-contained release builds bundle Microsoft's .NET and Windows Desktop runtimes. Their license text is copied from the restored Microsoft runtime packages into the release's `licenses/` folder. These runtime components are separate from the launcher's own source license. Runtime-pack provenance and versions are recorded in the build's standard NuGet restore assets.

The installed Claude Desktop application is not bundled. Anthropic's software, trademarks, and services retain their own applicable terms. Segoe UI is supplied by Windows and is not redistributed by this repository.
